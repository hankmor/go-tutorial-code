# 环境变量与配置示例

本目录对应高级篇《工程实践-环境变量与配置》和 Web 篇 530《工程实践-环境变量与配置》，使用 Go 1.25.1 验证。

示例覆盖：

- YAML 文件、默认值和 `APP_` 前缀环境变量合并；
- 显式覆盖值、环境变量、配置文件和默认值的优先级；
- 强类型配置和启动校验；
- 不覆盖现有环境变量的本地 `.env` 加载；
- 基于 `atomic.Value` 的不可变配置快照；
- 基于 `fsnotify` 的配置文件监听、防抖、校验和原子热更新；
- 不包含数据库用户名和密码的配置摘要。

运行验证：

```bash
go test ./config
go vet ./config
go test -race ./config
```

`config.example.yaml` 仅是本地模板。生产密钥应由部署平台或密钥管理服务提供，不应提交到代码仓库。
